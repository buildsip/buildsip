# Memory

Fields stored in [`memory.md`](../file-conventions/memory-md.md).

Built-in YAML fields: [`id`](./id.md), [`title`](./title.md), optional [`scope`](./scope.md), [`doNotEdit`](./doNotEdit.md), [`doNotDelete`](./doNotDelete.md). Extra fields must be declared in [`frontmatter.custom`](../config/frontmatter.md).

The Markdown after the closing `---` is the [`body`](./body.md).
